Features

Two layouts, one small native app.

අ

Phonetic (Singlish)

Type ammaa and get අම්මා. Your word stays underlined while you compose it.

Wijesekara

The standard SLS 1134 typewriter layout, for touch typists who already know it.

Inline English

Start a word with ? to keep it in English until the next space, in both layouts. Handy for names, emails and links.

Native & lightweight

Written in Swift with InputMethodKit. Works in every Mac app, with no accounts and no tracking.

Install

Pick one of three ways, then enable SiType in System Settings.

The recommended way. Updates come with brew upgrade.

brew install --cask mdev64/tap/si-type
  1. Download SiType-vX.Y.Z.zip from the Releases page and unzip it.
  2. Move SiType.app into ~/Library/Input Methods/.
  3. The app isn't notarized, so clear the quarantine flag and register it:
xattr -dr com.apple.quarantine ~/Library/Input\ Methods/SiType.app
~/Library/Input\ Methods/SiType.app/Contents/MacOS/SiType --register

Needs the Xcode Command Line Tools (xcode-select --install).

git clone https://github.com/mdev64/si-type.git && cd si-type && ./install.sh

Then turn it on

  1. 1

    Open System Settings → Keyboard → Input Sources → Edit…

  2. 2

    Click +, choose Sinhala, and add SiType - Phonetic and/or SiType - Wijesekara.

  3. 3

    Switch input sources from the menu bar, or with Control+Space or the 🌐 key.
